# cards/

One file per person. The wall is assembled from whatever is in here.

To add yours:

```
cp cards/_template.html cards/yourname.html
```

Then open your new file and change the three lines. That is the whole job.

Files beginning with `_` are ignored by the build, so `_template.html` never
appears on the wall.

**You only ever touch your own file.** That is deliberate — it is why four
people can work in here at once without standing on each other.
